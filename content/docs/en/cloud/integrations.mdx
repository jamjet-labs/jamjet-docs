# Cloud Integrations

JamJet Cloud's TypeScript and Python SDKs work with any framework that speaks OpenAI / Anthropic protocols. For frameworks with their own abstractions, dedicated integrations give you cleaner enforcement and richer telemetry.

<Cards>
  <Card title="Vercel AI SDK" href="/integrations/vercel-ai-sdk" description="`wrapLanguageModel` middleware. Streaming-aware policy enforcement." />
  <Card title="LangChain4j" href="/integrations/langchain4j" description="Records calls on the self-hosted JamJet runtime, not Cloud." />
  <Card title="Spring Boot" href="/integrations/spring-boot" description="Records ChatClient calls on the self-hosted JamJet runtime, not Cloud." />
  <Card title="Mastra / Express / CF Workers" href="/integrations" description="Coming soon." />
</Cards>

> The Vercel AI SDK integration is a thin adapter on top of `@jamjet/cloud`. The LangChain4j and Spring Boot integrations record on the self-hosted JamJet runtime. If your framework isn't listed, the bare SDK works too.
